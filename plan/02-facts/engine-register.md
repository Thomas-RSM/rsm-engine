# Engine register (v1.0)

"Engine" means any system that answers a customer's question. The D'Souza Equation applies to all of
them, so this list is open: a new engine is added as a row, with the date. Nothing is removed without a note.

Compiled 23 Nov 2026 from general knowledge of the market. Before any row is named on the site, its
current name and status are checked at the source.

Tracked means RSM asks it the client's mapped questions and records the answers. Covered means the work
is done so the business can be read, confirmed and chosen there.

## How a row is added

1. A new engine appears, or customers of a trade start using an existing one to find businesses.
2. It is added here with the date and whether it is tracked or covered.
3. If tracked, its prompts and recording method are added to the AI answer verification checks.
4. The public engine count is never a fixed number. The site says "every engine that answers your customers", and links to the list.
