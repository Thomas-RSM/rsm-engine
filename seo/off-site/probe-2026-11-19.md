## What this means

1. **Captcha is on nearly every group A site**, and captcha scoring is hostile to datacenter IPs.
   From the cloud, only sites with no captcha at all (Brownbook today) will complete.
2. **The allowlist cannot cover web signups.** Each page pulls assets from five to ten other
   hosts (CDNs, captcha providers, cookie-consent, payment). A 20-host list breaks most pages.
3. So the realistic split is: **account creation on a person's computer in Chrome, driven by
   Claude, on a residential IP**; **posting afterwards from the cloud by API** (WordPress.com,
   Tumblr, Blogger, Vimeo, Issuu, Pinterest, Reddit, Facebook/Instagram, LinkedIn, YouTube),
   which needs only a handful of stable API hosts.
4. Group A therefore means "needs only email, no phone, no owner" rather than "Claude alone
   from the cloud". The CSV's `who_does_it` column should read "Claude on your Chrome" for
   these, with the cloud used for the API posting that follows.
