# Films (HeyGen HyperFrames)

`equation.html` is "The D'Souza Equation", a 75-second, 9-scene HyperFrames composition authored to
HeyGen's "Send to HyperFrames" contract: one self-contained HTML, brand fonts and the logo inlined as
data URIs, a paused GSAP timeline registered on `window.__timelines.main`, one shader transition
(scene 6 → 7). Palette and type are RSM's own (navy, cream, gold; Inter Tight, Instrument Serif,
JetBrains Mono). Narration script is the transcript in the home page's equation section.

How to render it:
1. Open the design canvas (https://claude.ai/artifact/XRbUgXLXjPLA7j3e3LVCJN), board "Film-Equation.html",
   and use its **Send to HyperFrames** action; or
2. in HeyGen HyperFrames Studio, import this file.
Import and enhance are free; rendering the MP4 is the paid step. Add voice-over in the enhance step
(no synthetic Thomas; narrator only).

The composition could not be previewed from the build environment because the runtime scripts
(cdn.jsdelivr.net) are not reachable there; check it in HyperFrames before rendering.
